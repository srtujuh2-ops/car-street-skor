# 🏎️ Car Street Skor

Gim balap arkade 2D berbasis *browser* buatan anak PPLG menggunakan **HTML5 Canvas, CSS3, dan Vanilla JavaScript**. Pemain mengendalikan mobil putih melewati jalan raya 3 jalur untuk menghindari kendaraan rintangan dan mencetak skor tertinggi.

## 🎮 Fitur Utama
- **Kontrol Sentuh Responsif:** Navigasi 3 jalur (*◀ KIRI* dan *KANAN ▶*) yang nyaman dimainkan langsung di layar sentuh HP maupun desktop.
- **Skor & Rekor Tertinggi (*High Score*):** Perhitungan skor *real-time* beserta pencatatan rekor terbaik dalam satu sesi permainan.
- **Tingkat Kesulitan Bertahap:** Kecepatan laju kendaraan meningkat otomatis setiap kelipatan 50 poin.
- **Deteksi Tabrakan (*Collision Detection*):** Sistem pengecekan koordinat 2D untuk mendeteksi tabrakan antar kendaraan secara akurat.

## 🛠️ Teknologi yang Digunakan
- **HTML5 (`<canvas>`)** untuk arena permainan 2D
- **CSS3** untuk tata letak responsif dan tema antarmuka gelap (*Dark UI*)
- **JavaScript (ES6+)** untuk *game loop* (`requestAnimationFrame`), kontrol jalur, dan logika skor

## 🚀 Cara Memainkan
1. Buka tautan **GitHub Pages** (`https://github.io`) pada bagian *About* repositori ini.
2. Tekan tombol **◀ KIRI** atau **KANAN ▶** untuk berpindah jalur dan menghindari mobil di depan.
3. Kumpulkan skor setinggi mungkin dan tekan **MAIN LAGI ↻** untuk memulai ulang permainan.
